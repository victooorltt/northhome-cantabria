# Northome Cantabria

Sitio web y catálogo inmobiliario oficial para **Northome Cantabria** (Santander).

## 🚀 Tecnologías

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS](https://tailwindcss.com/)
- **Iconografía**: [Lucide React](https://lucide.dev/)
- **Diseño**: Tipografía Inter, paleta neutra y color de acento `#2A3142`.

## 📄 Estructura del Sitio

- **Inicio (`/`)**: Hero centrado con overlay, selección de propiedades destacadas, resumen de servicios, propuesta de valor y llamada a la acción.
- **Inmuebles (`/inmuebles`)**: Catálogo con filtros interactivos (tipo de propiedad, operación, zona y precio máximo).
- **Fichas individuales (`/inmuebles/[slug]`)**: Página dedicada para cada inmueble con galería fotográfica interactiva de alta resolución, visor a pantalla completa, características técnicas completas, descripción detallada y contacto directo.
- **Servicios (`/servicios`)**: Presentación con imágenes de los 4 servicios clave (Venta, Alquiler, Asesoramiento y Gestión de propiedades).
- **Nosotros (`/nosotros`)**: Trayectoria y valores de la agencia en Cantabria.
- **Contacto (`/contacto`)**: Canales directos, mapa embebido de Google Maps en Calle Floranes 10B (Santander) y formulario de contacto interactivo.
